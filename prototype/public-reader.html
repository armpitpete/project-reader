Public GitHub projects explained in ordinary language.

Privacy, safety and limits

Your browser asks GitHub directly for public repository information. Project Reader has no server, account, tracking form or GitHub write access.

GitHub can see those public API requests and applies an unauthenticated rate limit. Private repositories cannot be read.

Project Reader reports unknown when the repository does not provide enough evidence. It does not treat activity, open issues, code volume or age as proof of completion.
