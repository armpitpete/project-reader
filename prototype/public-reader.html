Privacy, safety and limits

Your browser asks GitHub directly for public repository information. Project Reader has no application account or GitHub write access.

Privacy-first Merrin Analytics records page views and uses a random site-local browser token only to estimate visitor numbers. The collector stores no IP address, raw visitor token, precise location or cross-site visitor identity.

The normal reading uses GitHub's public metadata API. If its anonymous request allowance is unavailable, Project Reader falls back to the public README through GitHub's raw-content service and labels the missing metadata.

Private repositories cannot be read. The fallback does not request or store a GitHub token.

The plain reading is produced by bounded rules, not a hosted artificial-intelligence service. It can still misunderstand unusual README structures, so the linked evidence remains available for checking.
