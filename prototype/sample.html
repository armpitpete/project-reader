Support tools

Python

What is it? A language used to give computers clear instructions.

What does it do here? It calculates project scores and prepares the project reading.

Why was it used? It is readable, widely supported, and works directly with Gitingest.

Evidence strength: confirmed

Where can I see it? The src/project_reader folder.

Why does it matter? Readable code makes the scoring rules easier to inspect and challenge.

Gitingest

What is it? A tool that gathers useful information from a Git repository.

What does it do here? It collects the repository structure and readable file contents.

Why was it used? It avoids rebuilding reliable repository extraction from scratch.

Evidence strength: confirmed

Where can I see it? The repository-ingestion layer.

Why does it matter? Project Reader can focus on meaning, evidence, and accessibility.
