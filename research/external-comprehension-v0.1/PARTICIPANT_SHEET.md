# Participant Sheet

Thank you for trying Project Reader.

Project Reader is being tested, not you. There are no right or wrong answers. Please say what makes sense, what is confusing, and what you would expect to happen next.

You can stop at any time. You can skip any question. You can ask for a note to be deleted before the session ends.

The session should take about 15-20 minutes.

Public pages:

- ordinary GitHub page: https://github.com/armpitpete/sample-hold-lab
- Project Reader page: https://armpitpete.github.io/project-reader/

What you will do:

1. Look at the ordinary GitHub page for up to three minutes.
2. Answer six questions about what the project appears to be, what appears finished or unfinished, how complete it seems, how likely the current plan seems to finish, and what evidence you trust or distrust.
3. Use Project Reader to read the same public GitHub project.
4. Answer the same six questions again.
5. Answer a few short usability questions.

Please do not share names, email addresses, medical details, school or workplace names, passwords, private repositories, or anything you do not want included in anonymous notes.

The useful result is honest feedback. Confusion is useful evidence because it shows what needs to be clearer.
