# Anonymous Record Templates

The checked-in `R01.json` through `R05.json` files are blank templates only.

Before a session, copy the relevant file outside the repository and fill in the copy. Keep completed records out of Git unless Merrin separately decides that a specific anonymized record is safe to store.

Rules:

- Use only anonymous IDs `R01` through `R05`.
- Record broad self-described categories only.
- Do not record names, email addresses, phone numbers, school names, workplace names, medical diagnoses, or other unnecessary identifying details.
- Keep participant statements separate from facilitator notes and interpretation.
- Use the paid-outcome values exactly as defined in `../PAID_OUTCOME_TEST.md`.
